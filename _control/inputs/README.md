# inputs · 本地原始材料

> **目的**：放从外部系统/历史项目**拷贝**进来的只读原始材料，作为 `_control/` 文档的取证来源。
> **原则**：只拷贝，不剪切；不修改原始内容；按子目录分类。

## 子目录

| 目录 | 用途 |
| --- | --- |
| `local-docs-raw/` | 从 `docs/` 或 blueprint 里拷贝出来便于集中查阅的关键文档 |
| `sealos/` | Sealos 部署相关原始资料（YAML、截图、配置导出） |
| `database/` | 数据库 schema 导出、样例 dump |
| `test-data/` | 测试用样例数据 |
