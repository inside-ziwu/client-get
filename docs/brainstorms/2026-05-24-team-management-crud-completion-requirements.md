# 团队管理 CRUD 完善

**日期：** 2026-05-24
**状态：** 待实施
**范围：** 前端 UI 补齐 + 显示优化

## 背景

租户端团队管理页面（`frontend/apps/tenant/src/app/(dashboard)/settings/team/page.tsx`）目前只实现了「创建成员」和「成员列表」，缺少编辑和删除操作。后端四个 CRUD 接口已全部就绪（`backend/app/api/tenant/team.py`），前端 API 客户端也已封装好 update/delete 方法（`frontend/packages/shared-api/src/tenant/team.ts`）。此外，角色和状态以英文原值展示，最近登录只显示日期。

设计参考：`docs/mock/tenant-settings-team.html`

## 需求

### R1 编辑成员

- 表格每行增加「编辑」操作按钮
- 点击弹出编辑弹窗，可修改：姓名、角色
- 角色使用下拉选择：管理员 / 运营 / 只读
- 当前登录账号不允许编辑自己的角色
- 调用 `PATCH /api/v1/team/users/{id}` 提交

### R2 删除成员

- 表格每行增加「删除」操作按钮
- 点击后弹出确认对话框
- 当前登录账号不允许删除自己
- 调用 `DELETE /api/v1/team/users/{id}` 提交

### R3 启用/禁用切换

- 表格每行增加「禁用」或「启用」按钮（根据当前状态显示对应文案）
- 当前登录账号不允许禁用自己
- 调用 `PATCH /api/v1/team/users/{id}` 提交 `{ status: 'active' | 'disabled' }`

### R4 角色中文化

- 表格角色列显示中文：
  - `admin` → 管理员
  - `operator` → 运营
  - `viewer` → 只读

### R5 状态中文化

- 表格状态列显示中文：
  - `active` → 已激活
  - `disabled` → 已禁用

### R6 最近登录时间格式

- 显示日期 + 时间，格式：`YYYY-MM-DD HH:mm`
- 未登录过显示 `-`

### R7 创建表单角色选择

- 创建表单增加角色下拉选择（管理员 / 运营 / 只读），默认选中「运营」
- 替换当前硬编码的 `roles: ['operator']`

## 不做的事

- 不改后端接口（已完备）
- 不改表格整体布局和列结构（保持现有分列方式）
- 不加角色权限说明卡片（暂不需要）
- 不加头像（保持简洁）

## 验收标准

1. 可编辑成员姓名和角色，保存后列表刷新
2. 可删除成员（非自身），确认后列表刷新
3. 可切换成员启用/禁用状态
4. 角色列显示中文
5. 状态列显示中文
6. 最近登录显示日期+时间
7. 创建表单支持选择角色
