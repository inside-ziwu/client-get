## 1. 全局架构

### 1.1 双端独立部署

| 属性 | 平台运营后台（Admin端） | 租户后台（Tenant端） |
|------|------------------------|---------------------|
| 域名 | `admin.xxx.com` | `app.xxx.com` |
| 用户 | 平台运营人员 | 租户管理员 / 业务员 / 只读观察者 |
| 独立React应用 | 是 | 是 |
| 共享组件库 | 是（抽取为内部npm包或monorepo共享） | 是 |
| 认证体系 | 独立JWT | 独立JWT（含tenant_id） |

**理由**：两端用户、权限模型、导航结构完全不同，独立部署避免路由/权限耦合，独立迭代互不影响。

### 1.2 通用布局

两端共享相同的布局结构（`AdminLayout` 模式）：

```
┌─────────────────────────────────────────────────────┐
│  顶部栏：面包屑导航 │ 通知铃铛 │ 用户头像+下拉菜单  │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  侧边栏   │              内容区                      │
│  (暗色)   │                                          │
│  240px   │                                          │
│  可折叠   │                                          │
│          │                                          │
├──────────┴──────────────────────────────────────────┤
│  底部（可选）：版本号 / 版权信息                       │
└─────────────────────────────────────────────────────┘
```

- **侧边栏**：暗色主题，240px宽，支持折叠至64px（仅图标）
- **顶部栏**：白色背景，包含面包屑、通知铃铛（租户端）、用户头像+下拉（个人信息/退出登录）
- **内容区**：白色/浅灰背景，左右padding 24px，上padding 24px

## 2. 通用设计规范

### 2.1 Ant Design组件使用约定

| 场景 | 组件 | 说明 |
|------|------|------|
| 数据列表 | `Table` (ProTable) | 支持排序、筛选、分页 |
| 详情查看 | `Drawer` | 宽度60%~70%，内部用`Tabs`分区 |
| 表单 | `Form` + `Form.Item` | 标准Ant Design表单布局 |
| 多步骤流程 | `Steps` + 分步表单 | 用于发送计划创建、首次登录向导 |
| 筛选面板 | `Form` (inline/horizontal) | 可折叠高级筛选 |
| 状态标签 | `Tag` | 颜色编码：S=金 A=绿 B=蓝 C=橙 D=灰 |
| 操作确认 | `Modal.confirm` | 删除、执行等不可逆操作 |
| 消息反馈 | `message` / `notification` | 操作成功/失败反馈 |
| 数据卡片 | `Card` + `Statistic` | Dashboard概览指标 |
| 图表 | ECharts 或 Ant Design Charts | 趋势图、柱状对比图、雷达图 |

### 2.2 评级颜色编码

| 评级 | 颜色 | Tag样式 | 含义 |
|------|------|---------|------|
| S | `#faad14`（金色） | `<Tag color="gold">S</Tag>` | 精准客户（励销云反查） |
| A | `#52c41a`（绿色） | `<Tag color="green">A</Tag>` | 优质 |
| B | `#1890ff`（蓝色） | `<Tag color="blue">B</Tag>` | 良好 |
| C | `#fa8c16`（橙色） | `<Tag color="orange">C</Tag>` | 一般 |
| D | `#bfbfbf`（灰色） | `<Tag color="default">D</Tag>` | 低优先 |

### 2.3 AI余额耗尽的全局UI行为

当租户AI余额 = 0时，以下按钮统一置灰：

| 按钮 | 位置 | 置灰文案 |
|------|------|---------|
| AI生成（邮件模板） | 模板库页 | `tooltip: "AI余额不足，请充值"` |
| AI分析（邮件监控） | 邮件监控页 | `tooltip: "AI余额不足，请充值"` |
| 情报AI摘要 | 情报中心 / Dashboard | 隐藏摘要内容，仅显示标题+原文链接 |

**非受影响功能**：邮件发送、公司浏览、数据筛选等核心操作不受余额影响。

### 2.4 通知组件（铃铛下拉）

仅租户端，位于顶部栏右侧：

```
🔔 (3)  ←  红色未读数气泡
 └─ 下拉面板 ──────────────────┐
 │  域名 mail.xxx.com 升级至第3阶段  │  2分钟前  │
 │  AI余额不足，当前余额 ¥12.30     │  1小时前  │
 │  采集任务完成，新增153家公司       │  3小时前  │
 │  ────────────────────────────── │
 │           全部标记已读            │
 └─────────────────────────────────┘
```

- 最多显示最近20条
- 点击单条可跳转相关页面
- 底部"全部标记已读"操作

## 附录 B：技术实现备注

| 项目 | 说明 |
|------|------|
| 状态管理 | 推荐引入 Zustand 或 Jotai（轻量级），替代纯 React Hooks，解决跨页面共享数据问题 |
| 图表库 | ECharts 或 @ant-design/charts（基于G2，与AntD风格统一） |
| 富文本编辑器 | 邮件模板编辑推荐 TinyMCE 或 Quill（支持变量插入） |
| 实时刷新 | 发送计划执行中 + 邮件监控 → 10s轮询（Phase 1）；后续可升级WebSocket |
| 路由守卫 | JWT校验 + RBAC角色检查 + 首次登录检测（重定向到向导） |
| 认证 | JWT存储于 localStorage → Axios拦截器自动附加 Bearer token，401自动跳转登录 |
