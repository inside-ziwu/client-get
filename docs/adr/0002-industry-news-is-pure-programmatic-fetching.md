# 行业动态是纯程序化抓取，不引入 LLM、浏览器渲染或外部抓取服务

行业动态只抓取标题 + 原文链接，按源配置的策略（RSS / HTML 列表选择器 / JSON-LD）确定性解析，不做翻译、摘要或相关度评分，也不引入 Playwright、Firecrawl、Crawl4AI 之类的引擎。2026-08 对客户确认的 13 个站逐站实测：全部服务端渲染、普通 HTTP 即可取到列表，6 站有 RSS；翻译与摘要的价值不足以换取 token 成本、租户级 AI 凭证依赖和不可重复的结果。LLM 的合理位置是接入新站时生成抓取配置初稿（人工验收），不在每日抓取路径上。2026-08-23 拍板（调研结论 + grill 第一轮）。

## Consequences

- 每日抓取零 token、零外部服务依赖；镜像不含浏览器。
- 每个源的全部属性（名称、地址、类别、语种、解析规则）由开发在仓库种子内维护，管理端只有启停开关、抓取健康与「立即抓取」，没有新增 / 编辑 / 删除表单。站点改版或新增站点是一次开发变更；抓取失败只影响该源当轮，不影响其他源。
- 标题以原文语种展示，并以语种标签提示。
